# Windows runner

The standard Flutter Windows runner is generated by the repository's GitHub Actions build workflow when this folder does not yet contain `CMakeLists.txt`. The runner and release binary are CI build outputs, not hand-edited app source.

For releases, the workflow also compiles `installer/VexoStream.nsi` with NSIS and publishes a per-user `VexoStream-<version>-Setup.exe` alongside the portable ZIP. The installer places the app under the current user's Local AppData, adds Start Menu shortcuts, and registers an uninstaller.
